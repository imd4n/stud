# GOTYFlight

Простой сайдскроллер «пролети над башней»: кодовая база взята из **«Игра»**
(иерархии `Location → Point → Plane` и `Point → Tower`, GDI-спрайты, окно Win32,
двойная буферизация), а механика — из **planeexamp** (гравитация, прыжок,
башни едут справа налево).

## Правила

- **Space / Up / W** — прыжок (flap); удерживать не нужно, важны моменты нажатия.
- Башни появляются справа и движутся влево, самолёт висит на одном месте.
  Расстояние между соседними домами случайное — от 1 до 4 ширин дома.
- Самолёт повёрнут на 90°: нос смотрит вправо, в сторону полёта (поворот
  делается матрицей GDI в `main.cpp`, сами спрайты не менялись).
- Хитбоксы считаются в `main.cpp` по видимому спрайту: у дома — только корпус
  (без тонкого шпиля/кристалла), у повёрнутого самолёта — его экранные габариты
  с небольшим отступом внутрь, чтобы касания краёв прощались.
- В HUD считается число башен, над которыми удалось пролететь (`FLIGHTS OVER`).
- Столкновение с башней или касание земли заканчивает залёт: вместо самолёта
  рисуется `BrokenPlane` с трещинами, дымом и обломками.
- **ESC** — выход.

Меню, стартовые и финальные экраны, облака, рекорды и прочие «плюшки»
намеренно отсутствуют.

## Сборка

Как и в «Игре»: открыть папку **GOTYFlight** корнем проекта в Zed и нажать **F5**
(`Compile & Run (C)`), либо **Alt+F6** — только сборка. Скрипт
`.zed/build-run.ps1` сам добавляет CMake, Ninja и MinGW в PATH и кладёт бинарник
в `output/GOTYFlight.exe`. Генератор Ninja выбран потому, что он, в отличие от
Unix Makefiles, нормально работает с кириллическими путями.

## Базовая часть
Описать класс граф. Класс должен содержать следующие обязательные функции: 
1) конструктор класса – принимает путь к файлу, в котором хранится граф/орграф и 
тип (ориентированный/неориентированный); 
2) size – возвращает количество вершин в графе/орграфе; 
3) weight – принимает номера двух вершин, возвращает вес ребра/дуги, 
связывающего их; 
4) is_edge – принимает номера двух вершин и возвращает True, если в 
графе/орграфе есть соответствующее ребро/дуга, False, если ребра/дуги нет; 
5) add_vertex – принимает номер вершины графа, добавляет соответствующую 
вершину в граф; 
6) add_edge – принимает номера двух вершин и вес ребра, добавляет 
соответствующее ребро в граф; 
7) list_of_edges – без аргументов возвращает список всех рёбер графа; с 
аргументом (номер вершины) возвращает список рёбер графа, инцидентных данной 
вершине / дуг, исходящих из данной вершины. 
Реализовать программу для работы с классом, с интерфейсом в виде командной 
строки. Поддерживаемые команды: 
- Создать пустой граф, считать граф из файла, добавить вершину, добавить ребро, 
удалить вершину/ребро, вывести список всех вершин/ребер графа; 
- Проверить связность графа и вывести компоненты связности графа, для орграфа – компоненты слабой связности и компоненты сильной связности; 
- Найти кратчайший путь и его длину между двумя заданными вершинами, найти 
расстояния от вершины до всех остальных вершин, вывести минимальное 
остовное дерево графа (для орграфа – без учёта направлений дуг). 
Варианты: 
1. Хранение графа во входном файле: 
a) файл со списком рёбер; 
b) файл со списками смежности; 
c) файл с матрицей смежности. 
2. Метод хранения графа в классе: 
a) в виде списков смежности; 
b) в виде матрицы смежности. 
3. Алгоритм нахождения расстояния между вершинами: 
a) Дейкстры, 
b) Беллмана-Форда; 
4. Алгоритм нахождения остовного дерева: 
a) Краскала; 
b) Прима.

## На 4 (после сдачи Базовой части) 
Реализовать консольное приложение со следующими параметрами командной 
строки: 
- имя входного файла (обязательный параметр); 
- имя выходного файла, задаётся после ключа -o. Если данный ключ не указан, 
пишется в файл по умолчанию (ans.txt). 
1. Входной файл: граф, являющийся транспортной сетью. 
Варианты задания графа: 
a) матрица смежности; 
b) списки смежности. 
Необходимо найти максимальный поток в сети, реализовав соответствующую 
версию алгоритма Форда-Фалкерсона. 
Выходной файл: текстовый файл, в котором указывается:  
- источник и сток; 
- суммарная величина потока; 
- список рёбер, величина потока на каждом ребре и пропускная способность для 
каждого ребра. 
2. Входной файл: карта, заданную в виде двумерной матрицы, представляющая 
собой строки со значениями «высот», разделёнными пробелами. Высота 0 означает, 
что прохода нет. После обязательного ключа -a через пробел указываются 
координаты точки начала пути. После ключа -b – координаты точки конца пути. 
Реализовать следующие алгоритмы: 
a) Дейкстры и A* (с эвристикой Чебышева); 
b) A* (с эвристиками Евклидовой и Манхэттенской). 
Выходной файл: представляет собой текстовый файл, в котором для каждого из двух 
алгоритмов указывается: 
- длина найденного пути; 
- вершины, составляющие путь; 
- процент просмотренных вершин от общего числа вершин в графе; 
- время выполнения алгоритма. 
3. Входной файл: граф, заданный в виде матрицы смежности или списка рёбер. 
Проверить, является ли граф двудольным и для двудольного графа найти 
максимальное паросочетание. 
Выходной файл: текстовый файл, в котором указано:  
- является ли граф двудольным; 
- число паросочетаний (для двудольного графа); 
- размер максимального паросочетания (для двудольного графа); 
- ребра, входящие в паросочетание (для двудольного графа). 


## На 5 (после сдачи части «На 4») 
1. Реализовать поиск минимального остовного дерева в графе посредством 
алгоритма Борувки. на параллельных потоках. Консольное приложение должно 
принимать следующие параметры командной строки: 
- имя входного файла (обязательный параметр); 
- количество потоков (задаётся ключом -n) – если количество потоков не 
задано, по умолчанию – 4 потока; 
- имя выходного файла (задаётся после ключа -o). Если не указан выходной 
файл, ответ пишется в файл по умолчанию (ans.txt). 
Входной файл содержит граф, заданный списками смежности. 
Выходной файл представляет собой текстовый файл, в котором указывается:  
- время выполнения алгоритма и количество потоков; 
- суммарный вес рёбер минимального остовного дерева; 
- ребра, входящие в минимальное остовное дерево. 
2. Реализовать алгоритм гамма-алгоритм проверки планарности графа. 
Консольное приложение должно принимать следующие параметры командной 
строки: 
- имя входного файла (обязательный параметр); 
- имя выходного (задаётся после ключа -o). Если не указан выходной файл, 
ответ пишется в файл по умолчанию (ans.txt). 
Входной файл содержит граф, заданный матрицей смежности. 
Выходной файл представляет собой текстовый файл, в котором указано: 
- является ли граф планарным; 
- перечислены все грани плоской укладки графа. 
3. Реализовать структуру данных – дерево бинарного поиска. 
Написать приложение, считывающее числовой массив из входного файла и 
хранящее его в описанной структуре. Интерфейс приложения представляет собой 
командную строку со следующими командами для работы с данными: 
- поиск элемента, вставка элемента, удаление элемента; 
- вывод минимального элемента, вывод 10 минимальных элементов; 
- вывод максимального элемента, вывод 10 максимальных элементов. 
После выполнения каждой из операций на экран выводится результат и время 
выполнения операции. 
Варианты: 
a) красно-чёрное дерево, 
b) рандомизированное дерево бинарного поиска, 
c) АВЛ-дерево.
